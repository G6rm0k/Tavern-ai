# wesaid

Чат с ИИ-персонажами, который работает на твоём компьютере. Переписки никуда не уходят
и хранятся зашифрованными.

---

## Запуск

### Готовый файл (проще всего, Node.js не нужен)

Открой [Releases](https://github.com/G6rm0k/Tavern-ai/releases/latest) и скачай файл под свою систему:

- Windows — `wesaid-windows.exe`
- macOS — `wesaid-macos`
- Linux — `wesaid-linux`

Двойной клик — и готово. Данные сохраняются в папке `data` рядом с файлом.
На macOS/Linux может понадобиться разрешить запуск один раз: `chmod +x wesaid-macos`.

### Windows, из исходников

1. Скачай архив с проектом ([Code → Download ZIP](https://github.com/G6rm0k/Tavern-ai)) и распакуй
2. Дважды кликни **`start.bat`**

Если Node.js не установлен, скрипт предложит поставить его сам. Браузер откроется
автоматически, когда всё будет готово.

### macOS и Linux, из исходников

```bash
./start.sh
```

Если файл не запускается, сначала выполни `chmod +x start.sh`.

### Вручную

```bash
npm install
npm start
```

Порт по умолчанию `3000`; если он занят, приложение само возьмёт следующий свободный.
Задать свой можно так: `PORT=8080 npm start`.

## Первый запуск

После регистрации приложение спросит, как ты хочешь подключить ИИ, и предложит три пути:

| Вариант | Что это | Нужен ключ |
|---|---|---|
| 🆓 **Бесплатно через интернет** | OpenRouter, там есть бесплатные модели | Да, бесплатный |
| 💻 **Бесплатно на своём ПК** | Ollama или LM Studio, ничего не уходит в сеть | Нет |
| 🔑 **Свой ключ** | Любой OpenAI-совместимый сервис | Да |

Для первого варианта будет пошаговая инструкция, где взять ключ. Кнопка **«Проверить»**
сразу скажет, работает ли подключение, — не придётся выяснять это методом тыка.

Если Ollama или LM Studio уже установлены, приложение найдёт их само и предложит
подключить в один клик.

> ⚠️ Пароль от аккаунта — это ключ шифрования твоих переписок.
> **Восстановить его невозможно.** Забудешь — данные не прочитать.
>
> На компьютерах с Windows Hello / Touch ID можно один раз включить **вход по
> отпечатку** в Настройках — пароль вводить не придётся, но он остаётся
> запасным способом входа.

## Возможности

- **Персонажи** — имя, аватар, характер, несколько вариантов первого сообщения,
  база знаний с ключевыми словами. Импорт PNG-карточек и JSON, поиск по Chub.ai
- **Чат** — потоковые ответы, форматирование (`*действие*`, **жирный**, `код`),
  свайп между вариантами ответа (‹ 2/3 ›), несколько отдельных историй с одним
  персонажем, кнопка «Стоп»
- **Персона** — кто ты в глазах персонажа: имя и пара слов о себе вместо {{user}}
- **Память** — в длинных чатах старые сообщения сжимаются в краткое содержание,
  чтобы персонаж их не забывал (по желанию, в Настройках)
- **Сервисы** — любой OpenAI-совместимый API плюс Anthropic; ключи хранятся зашифрованными
- **Настройки модели** — три пресета словами, остальное спрятано в «Продвинутые»
- **Резервные копии** — выгрузка всего в один файл и восстановление из него
- **Телефон** — QR-код в настройках, приложение ставится на домашний экран
- **Оформление** — тема, цвет акцента, размер текста, язык (русский / английский)
- **Проверка обновлений** и ярлык на рабочий стол / автозапуск (Windows)

## Поддерживаемые сервисы

Любой **OpenAI-совместимый** API — впиши адрес и ключ в настройках:

| Сервис | Адрес (Base URL) |
|---|---|
| [OpenRouter](https://openrouter.ai) | `https://openrouter.ai/api/v1` |
| [VseGPT](https://vsegpt.ru) | `https://api.vsegpt.ru/v1` |
| OpenAI | `https://api.openai.com/v1` |
| Anthropic | `https://api.anthropic.com/v1` |
| Ollama (локально) | `http://localhost:11434/v1` |
| LM Studio (локально) | `http://localhost:1234/v1` |
| Groq, Together, Mistral, DeepSeek, Cohere, xAI | см. список в настройках |

## С телефона

1. Запусти приложение на компьютере
2. Открой **Настройки → Открыть на телефоне**
3. Наведи камеру телефона на QR-код

Телефон должен быть в той же Wi-Fi сети. Там же можно нажать «Установить приложение»,
чтобы оно появилось на домашнем экране без адресной строки.

## Где лежат данные

Всё в папке `data/` рядом с приложением:

```
data/
├── users.json          # аккаунты (пароли — bcrypt)
├── characters.json     # персонажи
├── chats.json          # переписки
├── settings.json       # настройки и ключи сервисов
├── avatars/            # картинки
└── *.bak1 / *.bak2     # автоматические резервные копии
```

Шифруются паролем: ключи API, описания и промты персонажей, тексты сообщений.
Файлы записываются атомарно, а повреждённый файл автоматически восстанавливается
из резервной копии.

Чтобы перенести всё на другой компьютер, проще всего сделать резервную копию
через **Настройки → Данные → Скачать резервную копию**.
